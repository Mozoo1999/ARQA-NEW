# نموذج التسعير الذكي

واجهة ثابتة أولية للمرحلة الأولى. افتح `index.html` في المتصفح لتجربة أثر سعر الشراء والنقل والهالك والمصروف الإداري وهامش الربح.

هذا النموذج لا يحفظ بيانات ولا يتصل بواجهة خلفية بعد؛ وهو واجهة تحقق لفلسفة سلسلة التكلفة قبل بناء النظام الإنتاجي.

يتضمن أيضًا شريط أوامر نصية وصوتية تجريبيًا عبر `voice-command.js`. يستعمل دعم التعرف على الصوت الموجود في المتصفح عند توفره، ويعرض مسودة قسط أو تحصيل تتطلب تأكيدًا؛ لا يتصل بقاعدة بيانات أو WhatsApp في هذه الواجهة الثابتة.

تضم الواجهة أيضًا بطاقة اقتراح مالي توضيحية تمثل إشعارًا مصرحًا به. زر «إضافة كمسودة» يحاكي إنشاء مسودة فقط؛ الربط الفعلي بمستقبل إشعارات Android وواجهة API يحتاج تطبيق هاتف وخدمة خلفية.
