# Expo Text Extractor — Integration Notes

Source reviewed: <https://github.com/pchalupa/expo-text-extractor>

The library offers on-device text extraction using Google ML Kit on Android and Apple Vision on iOS. Its repository documents support for Expo 52+ and includes Android image-picker handling for API 34 and camera-image extraction. It therefore represents a possible native pre-processing/OCR path in an Expo prebuild application.

The library documentation reviewed does not provide verified Arabic-script accuracy claims. Any extracted text must remain a reviewable draft and must not be posted to financial records without the existing user-approval flow. The selected mobile implementation will expose confidence and review guidance rather than claim recognition is error-free.
