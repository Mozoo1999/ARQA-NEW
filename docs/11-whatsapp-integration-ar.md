# تكامل WhatsApp Business

## ما يدعمه التكامل

1. استقبال رسالة العميل أو المورد ومرفقاته بواسطة Webhook.
2. حفظ المحادثة وربطها تلقائيًا بجهة الاتصال عند تطابق رقم الهاتف.
3. تحليل الرسائل والمرفقات واقتراح: مطالبة، دفعة، طلب عرض، شكوى، أو مهمة.
4. تجهيز مطالبة أو تذكير من ذمم العميل ثم إرساله من قناة واتساب معتمدة.
5. تتبع حالة الإرسال والتسليم والقراءة والرد، مع عدم اعتبار «تم الإرسال» تحصيلًا أو قبولًا.

## متطلبات التفعيل الخارجي

- حساب WhatsApp Business وربطه بمزود رسمي أو WhatsApp Cloud API.
- رقم أعمال مخصص وتفويض Meta ومفاتيح اتصال تحفظ في خزنة أسرار.
- قوالب رسائل معتمدة للرسائل الاستباقية، بحسب قواعد المنصة والمنطقة.
- موافقة العميل ووسيلة إيقاف الرسائل، وسياسة احتفاظ بالمحادثات.
- عنوان Webhook موثوق ومعالجة توقيع الطلب وإعادة المحاولة ومنع التكرار.

لا يمكن تفعيل إرسال أو استقبال حقيقيين من المستودع وحده؛ هذه المتطلبات تتطلب بيانات اعتماد وحساب أعمال يملكه العميل.

## عقود الأحداث

### رسالة واردة

```json
{
  "channel": "whatsapp",
  "direction": "inbound",
  "providerMessageId": "wamid...",
  "from": "+201...",
  "receivedAt": "2026-08-16T10:00:00Z",
  "text": "تم التحويل",
  "attachments": [{"type": "image", "objectKey": "private/..."}]
}
```

### طلب إرسال مطالبة

```json
{
  "customerId": "customer-123",
  "collectionCaseId": "collection-45",
  "channel": "whatsapp",
  "templateCode": "payment_reminder_ar",
  "variables": {"customerName": "شركة العالمية", "amount": 30000, "dueDate": "2026-09-01"}
}
```

## الضوابط

- يرسل المستخدم فقط إلى جهة اتصال لديها موافقة وقناة صالحة.
- يعاين المستخدم النص والقالب قبل أول إرسال أو عند تغيير البيانات الحساسة.
- يمنع التكرار بالاعتماد على معرّف الرسالة الخارجي ومفتاح إرسال داخلي.
- لا تستخرج الدفعات من الرسالة وحدها كتحصيل نهائي؛ تطابق مع مستند أو تأكيد.
