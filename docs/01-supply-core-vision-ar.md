# ARQA — المرحلة الأولى: نواة التوريدات وسلسلة التكلفة

## الغاية

إنشاء نواة قرار للتوريدات في شركات المقاولات والتوريد. لا تتعامل ARQA مع المادة كسعر ثابت؛ بل تحسب **تكلفتها الفعلية عند موقع وتسليم ووقت محددين**.

> سلسلة التكلفة: المورد ← المادة ← المصدر ← التحميل ← النقل ← الانتظار والرسوم ← منطقة التسليم ← الهالك ← المصاريف الإدارية ← هامش الربح.

## قرارات يجب أن يدعمها النظام

- اختيار المصدر صاحب أقل **تكلفة هابطة**، لا أقل سعر شراء فقط.
- مقارنة الموردين بحسب التكلفة، الجودة، الطاقة، الالتزام والمدة.
- توليد سعر بيع مقترح لعطاء أو أمر توريد.
- حفظ تاريخ كل سعر وإعادة إنتاج قرار التسعير في المستقبل.
- توزيع كمية المشروع على مصادر متعددة عند الحاجة إلى تقليل الوقت أو المخاطر.

## النطاق في المرحلة الأولى

| داخل النطاق | خارج النطاق مؤقتًا |
| --- | --- |
| الموردون والمحاجر والمواد والمصادر | إدارة المخازن الفعلية |
| أسعار شراء ونقل مؤرخة | القيود المحاسبية والترحيل |
| محرك تكلفة قابل للتفسير | تتبع GPS المباشر |
| عروض سعر ذكية ومقارنة بدائل | تحسين آلي متقدم بالذكاء الاصطناعي |
| المشاريع والعملاء ومناطق التسليم | إدارة الموارد البشرية |

## المصطلحات

- **المنتج**: مادة قابلة للتوريد، مثل سن 1 أو رمل أو أسمنت.
- **المصدر**: موقع شراء مادة لدى المورد، وقد يكون محجرًا أو مصنعًا أو مخزنًا.
- **المسار**: مصدر + منطقة تسليم + وسيلة نقل.
- **السعر الساري**: سعر له بداية نفاذ ونهاية اختيارية؛ لا تُعدّل السجلات التاريخية.
- **التكلفة الهابطة**: تكلفة وحدة المادة بعد إيصالها إلى الموقع وقبل هامش الربح.
- **عرض التسعير**: لقطة ثابتة من عناصر التكلفة المستخدمة في قرار البيع.

## قواعد عمل غير قابلة للتفاوض

1. لا يجوز حفظ سعر شراء أو نقل بلا عملة ووحدة قياس وتاريخ بداية.
2. لا يحل سعر جديد محل القديم؛ ينشئ فترة سريان جديدة.
3. يجب أن ينتمي كل بند تكلفة إلى عرض تسعير أو رحلة أو أمر توريد قابل للتتبع.
4. لا يمكن مقارنة مصدرين ما لم تتطابق وحدة القياس، أو تُحفظ قاعدة التحويل بوضوح.
5. يظل قرار النظام اقتراحًا: يمكن للمستخدم تجاوزه بشرط إدخال سبب.
6. تُخزن كل المدخلات التي كوّنت العرض كي لا تتغير ربحية العرض بأثر رجعي.

## مؤشرات المرحلة الأولى

- الفرق بين السعر المقدر والتكلفة الفعلية لكل نقلة.
- أقل تكلفة هابطة لكل منتج ومنطقة.
- نسبة الالتزام بالمواعيد لكل مصدر وناقل.
- هامش الربح المتوقع والفعلي لكل مشروع.
- نسبة التوصيات التي قبلها المستخدم أو تجاوزها.
