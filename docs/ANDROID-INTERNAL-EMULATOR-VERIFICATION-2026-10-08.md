## ما نفذه خط الإصدار الناجح

1. ثبّت الاعتمادات من قفل التبعيات، ثم شغّل TypeScript للجوال.
2. أنشأ مشروع Android من إعداد Expo باستخدام `expo prebuild --clean`.
3. بنى الحزمة القابلة للتوزيع للهاتف بمعمارية `arm64-v8a`، وحفظها خارج مخرجات Gradle كي لا تستبدلها حزمة المحاكي.
4. فحص حزمة الهاتف بـ `aapt` و`unzip`: المعرّف، ABI، ووجود `assets/index.android.bundle`، إضافة إلى منع الأذونات المحظورة.
5. بنى نسخة `x86_64` منفصلة للاختبار فقط، ثم ثبتها وشغلها على Android Emulator API 35 في GitHub Actions.
6. تحقق من عملية التطبيق، والنشاط الأمامي، وغياب `FATAL EXCEPTION`، وحفظ سجل ولقطة شاشة للاختبار.

## دليل المحاكي

حزمة المحاكي `x86_64` ليست حزمة التوزيع. استعملت فقط لتشغيل المصدر نفسه في بيئة Android API 35 لا تدعم ABI الهاتف `arm64-v8a`.

| الفحص | الدليل |
|---|---|
| تثبيت الحزمة | سجل Android يثبت تثبيت `com.narqa.ebos` وإعداد Dex لـ `x86_64` |
| تشغيل النشاط | `Displayed com.narqa.ebos/.MainActivity` |
| تشغيل JavaScript | `ReactNativeJS: Running "main"` |
| واجهة فعلية | لقطة المحاكي تعرض شاشة NARQA EBOS الرئيسية وخيارات الأمر الصوتي وتحليل المستند والفاتورة والتقرير |
| فحص الانهيار | بوابة CI تتحقق من غياب `FATAL EXCEPTION` للحزمة |

النطاق المثبت هنا هو **التثبيت والإقلاع وظهور الواجهة فقط**. لا يثبت التعرف الصوتي أو الكاميرا أو OAuth أو تحليل وثيقة حقيقية أو إدراج سجل، لأن هذه السيناريوهات تتطلب أذونات وحساباً مصادقاً ومراجعة مستخدم حقيقية.

## التثبيت الداخلي على هاتف Android

1. نزّل `narqa-ebos-arm64-v8a-internal.apk` من [تشغيل GitHub Actions الناجح](https://github.com/Mozoo1999/ARQA-NEW/actions/runs/37815936802) (artifact: `narqa-ebos-internal-release-apk`)، أو استخدم ملف التسليم المحلي المرفق.
2. تأكد أن الهاتف Android بمعمارية `arm64-v8a` وإصدار Android 7.0/API 24 أو أحدث.
3. قارن SHA-256 بالقيمة أعلاه قبل التثبيت.
4. افتح الملف من مدير الملفات، وافق على السماح بالتثبيت من المصدر المحدد، ثم اختر **تثبيت**.
5. ابدأ من شاشة التطبيق، وامنح الكاميرا أو الميكروفون أو جهة الاتصال فقط عند اختيار الإجراء المقابل.

> GitHub Actions يحتفظ بالـ artifact لمدة 14 يوماً. احفظ نسخة داخلية موثقة إذا كانت هناك حاجة للاحتفاظ بها بعد ذلك.

## حدود تمنع وصفه بالإصدار الإنتاجي النهائي

1. **توقيع Android:** الحزمة ما زالت موقعة بشهادة Android Debug. لم يقدَّم مفتاح إصدار مملوك للمؤسسة أو صلاحية موثقة لإدارة GitHub Actions Secrets؛ حساب CLI الحالي أعاد `403 Resource not accessible by integration` عند طلب قائمة الأسرار. لا يجوز توليد مفتاح مزيف أو وضع مفتاح/كلمة مرور في المستودع.
2. **اختبار هاتف مادي:** لا يوجد بعد اختبار على هاتف Android فعلي بحساب مصادق وسيناريو OAuth، ميكروفون، كاميرا/ملف PDF، وتأكيد إدراج محفوظ.
3. **iPhone/iPad:** لا يوجد IPA أو TestFlight أو اختبار جهاز iOS/iPad. يتطلب ذلك فريق Apple Developer، شهادة وتوفيراً وتوقيعاً معتمداً.
4. **WhatsApp Business:** ما زال `not_configured` إلى أن تتوفر بيانات Meta Business الرسمية وWebhook موقع وسياسة موافقة/احتفاظ. لا توجد مراقبة SMS أو كشط WhatsApp.

لذلك الحزمة الحالية **صالحة للتثبيت والتقييم الداخلي على Android arm64**، لكنها ليست صالحة للوصف كنسخة إنتاجية عامة أو إصدار iOS مكتمل.
