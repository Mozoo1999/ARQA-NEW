# نطاق MVP — المقاولات والتوريدات

## الهدف التشغيلي

يمكّن الـMVP فريق المبيعات والمشتريات والتشغيل ومدير المشروع من إدارة دورة واحدة متصلة:

```text
عميل ← مشروع ← احتياج مادة ← تسعير ذكي ← عرض سعر ← اعتماد
     ← أمر شراء/توريد ← رحلات ← فاتورة/تحصيل ← تكلفة وربحية فعلية
```

## الوحدات وأولوياتها

| الوحدة | ما يدخل الـMVP | ما يؤجل بعده |
| --- | --- | --- |
| CRM والعملاء | العملاء، جهات الاتصال، حدود الائتمان، سجل التعاملات | حملات تسويقية وأتمتة بيع متقدمة |
| العقود والمشاريع | العقود، مشاريع العميل، مواقع التسليم، احتياجات المواد، ميزانية أولية | تخطيط زمني تفصيلي وBIM |
| الموردون والمصادر | المورد، محجر/مصنع، طاقة، ساعات عمل، جودة، التزام، طرق دفع | تقييم آلي تنبؤي |
| المنتجات والأسعار | منتجات، وحدات وتحويلات، مصادر بديلة، أسعار شراء مؤرخة | تسعير موسمي تنبؤي |
| التسعير وعروض الأسعار | سلسلة التكلفة، بدائل، هامش، اعتماد، لقطة تاريخية | اقتراح هامش تلقائي كامل |
| الأسطول والنقل | أنواع شاحنات، سائقون، ناقلون فرعيون، حمولة، تكلفة مسار | تتبع GPS حي وصيانة تنبؤية |
| الرحلات | تحميل/خروج/وصول/تفريغ، وزن، انتظار، صور، توقيع | دمج مباشر مع أجهزة وميزان |
| المشاريع | كميات مخططة ومنفذة، إيراد، مصروف وتكلفة فعلية | تخطيط عمالة ومعدات تفصيلي |
| المالية التشغيلية | فواتير، مدفوعات، ذمم، مراكز تكلفة وربحية | دفتر عام كامل وضرائب محلية مؤتمتة |

## قصص المستخدم الجوهرية

### مسؤول التسعير

يختار مشروعًا ومادة وكمية وموعدًا؛ يرى بدائل المورد/النقل وترتيبها، ثم يعتمد سعر بيع مبنيًا على لقطة تكاليف محفوظة.

### مسؤول المشتريات

يحوّل العرض المعتمد إلى أوامر شراء وتوريد، مع تحديد المصدر والكمية وشروط الدفع.

### مسؤول التشغيل

يخطط النقلات، يسجل أوقات الرحلة والوزن والانتظار وصور الاستلام، ويعالج الاستثناءات.

### مدير المشروع

يرى الاحتياج المخطط والمنفذ والتكلفة والإيراد والهامش والانحراف لكل مادة ولكل مشروع.

### الإدارة المالية

تراجع الفواتير والتحصيل والمدفوعات ومراكز التكلفة، مع رابط واضح للعرض والرحلة وأمر التوريد.

## حالات الاعتماد

- اعتماد عرض يتجاوز حد خصم أو هامش أدنى.
- اعتماد أمر شراء فوق حد مالي.
- تغيير تكلفة رحلة أو وزن بعد الإغلاق.
- تجاوز حد ائتماني للعميل.
- إغلاق فترة مالية أو مشروع.

كل اعتماد يسجل: المستخدم، الوقت، السبب، قبل/بعد، والمرجع التشغيلي.

## مؤشرات نجاح الـMVP

- زمن إعداد عرض سعر لمادة وموقع محددين.
- دقة التكلفة التقديرية مقابل الفعلية.
- هامش الربح الفعلي حسب مشروع وعميل ومادة.
- نسبة وصول النقلات في الموعد.
- التزام الموردين بالكمية والجودة.
- متوسط التحصيل والذمم المستحقة.

## ما لا يجب بناؤه الآن

- وكلاء يتخذون قرارًا ماليًا أو تشغيليًا تلقائيًا.
- دمج أجهزة ميدانية قبل وجود دورة رحلة ناضجة.
- محاسبة قانونية لعدة دول قبل تثبيت مراكز التكلفة والتدفقات التشغيلية.
- تطبيقات منفصلة لكل وحدة؛ البداية تكون تطبيقًا واحدًا منظمًا إلى وحدات واضحة.
