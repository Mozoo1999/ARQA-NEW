- معاينة `/app` عند لوحي `768×1024` أظهرت مركز تحكم RTL، تنقل جانبي، بطاقات ذات أولوية ومساحة تشغيل فعلية.
- معاينة Expo Web للوحة الجوال أظهرت صفحة رئيسية متكيفة للوحيات، ثم شاشة سياق العمل عند الانتقال إليها. في حالة عدم وجود جلسة ظهرت رسالة دخول صريحة ولم تُعرض حقول ملف شخصي وهمية.
- وحدة تحكم Expo Web لم تعرض أي مخرجات بعد فتح شاشة السياق.

## سلامة الأداء الوظيفي

استعمال ملف سياق التشغيل لا يضيف طلباً عاماً إلى الصفحة العامة. تستدعي واجهة الجوال السياق بعد وجود جلسة المستخدم فقط، وتستخدم `AbortController` عند مغادرة شاشة السياق أو تبدل المستخدم. خدمة الصوت تقبل المفردات المحلية ووسم اللهجة داخل جلسة مرئية فقط، ولا تضيف معالجة خلفية.

## حدود القياس

لا توجد أرقام Core Web Vitals من جهاز مستخدم أو شبكة جوال حقيقية. لا يقيس هذا السجل مدة تحميل Expo native أو زمن استجابة نماذج الذكاء الاصطناعي أو زمن PDF كبير. يجب أخذ هذه القياسات من هاتف Android وiPhone/iPad فعليين قبل إعلان جاهزية الإنتاج العامة.
