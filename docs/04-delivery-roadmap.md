# خارطة تنفيذ المرحلة الأولى

## 1. مرجع الأعمال والبيانات

- اعتماد وحدات القياس وقواعد التحويل.
- تعريف أنواع المصروفات وسندات اعتمادها.
- إدخال موردين ومصادر ومناطق تسليم تجريبية.
- وضع سياسة تاريخ الأسعار والعملات والصلاحيات.

**معيار القبول:** يستطيع مسؤول التوريدات إضافة مصدر وسعره وفترة سريانه بلا فقدان للتاريخ.

## 2. محرك التكلفة

- حساب تكلفة الشراء والنقل والتحميل والإضافات والهالك.
- تسعير مقترح حسب المصروف الإداري والهامش.
- مقارنة بدائل مصدر/نقل مع أسباب الترتيب.
- حفظ لقطة مدخلات ومخرجات كل عرض.

**معيار القبول:** مثال سن 1 يختار كسارة B بتكلفة 154 جنيه/طن، لا كسارة C الأرخص شراءً.

## 3. الواجهات الأساسية

- شاشة المورد والمصدر.
- شاشة المنتج مع مقارنة المصادر.
- شاشة طلب عرض السعر.
- شاشة عرض التسعير وتفسيره.
- شاشة المشروع واحتياجات المواد.

**معيار القبول:** ينشئ المستخدم عرض سعر دون إدخال سعر بيع يدويًا.

## 4. التشغيل والتحقق

- أوامر شراء وتوريد.
- رحلات شاحنات ومصروفات فعلية.
- مقارنة التقديري بالفعلي وتحليل الانحراف.
- صلاحيات واعتمادات وتدقيق.

**معيار القبول:** يمكن تتبع هامش الربح الفعلي لنقلة من عرض السعر حتى مصروفاتها.

## قرارات مطلوبة قبل الإنتاج

1. هل ستكون وحدة المحاسبة الأساسية للسن والرمل طنًا أم مترًا مكعبًا، وهل توجد كثافة تحويل معتمدة؟
2. ما أنواع الشاحنات والحمولات القياسية في التشغيل؟
3. هل تكلفة النقل تفاوضية لكل نقلة أم لكل طن أم لكليهما؟
4. ما نسب الهالك والمصروف الإداري الافتراضية، ومن يحق له تعديلها؟
5. ما نظام الصلاحيات: مشتريات، تسعير، تشغيل، مدير؟
